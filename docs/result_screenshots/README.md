## 使用说明

本目录仅保存调度运行截图、单日 ADS 指标查询结果截图和轻量级看板展示截图，用于项目运行验收与面试讲解。

多天分区验证、区间回刷、幂等性检查和 T+1 修正窗口验证截图，请放入：

```text
docs/result_screenshots_validation/
```

所有截图仅作为项目工程链路验证材料，不作为真实业务运营结论。公开仓库截图中不得展示真实服务器账号、真实 IP、明文密码、本机绝对路径或其他敏感信息。

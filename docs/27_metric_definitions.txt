项目指标口径说明

一、文档目的
本文档用于统一说明本项目中的核心指标定义、统计范围和结果解释边界，保证 README、SQL 脚本、Hive 迁移文档、调度文档和结果截图中的指标表达保持一致。

二、数据范围
1. 数据来源：电商零售订单数据，围绕订单、客户、商品、国家等维度进行建模与分析。
2. 统计范围：所有指标默认基于清洗后的有效订单数据统计，不包含异常订单和无效记录。
3. 清洗规则：过滤商品数量小于等于 0、商品单价小于等于 0、CustomerID 为空或空字符串、Invoice 为空或以 C 开头的退货订单。
4. 金额字段：amount = Quantity * Price，用于客户价值分层、销售贡献分析、国家销售汇总和商品偏好分析。
5. 日期口径：Hive 阶段通过 bizdate 参数控制业务日期，各层结果表使用 dt 分区保存同一业务日期的数据。

三、Hive 阶段核心指标
1. 总销售额：指定 dt 分区内清洗后有效订单明细 amount 之和。
2. 总订单数：指定 dt 分区内清洗后去重订单编号数量。
3. 总客户数：指定 dt 分区内清洗后去重客户编号数量。
4. 客户价值分层：Hive 主链路按指定 dt 分区内客户消费金额划分 High Value、Medium Value、Low Value；该口径为业务日期分区口径，不代表历史累计消费。
5. 高价值客户：客户价值分层结果中 customer_level = 'High Value' 的客户。
6. 客户层级人数占比：某一客户层级人数占总客户数的比例。
7. 客户层级销售贡献占比：某一客户层级销售额占总销售额的比例。
8. 高价值客户销售贡献占比：高价值客户贡献销售额占平台总销售额的比例。
9. 高价值客户订单数：高价值客户产生的去重订单数量。
10. 高价值客户人均销售额：高价值客户总销售额除以高价值客户人数。
11. 高价值客户人均订单数：高价值客户总订单数除以高价值客户人数。
12. 国家销售汇总：按国家维度统计订单数、客户数、销售额和平均订单金额。
13. 国家销售排行：基于国家销售汇总表，按 total_sales 降序生成 sales_rank。
14. 高价值客户偏好商品：仅在高价值客户群体内统计商品的客户数、订单数、购买数量、销售额和销售额排名。

四、MySQL 阶段扩展指标
MySQL 阶段还包含复购率、月度销售趋势、Top 客户收入集中度、商品销售集中度、客户下单频次等扩展指标。这些指标用于展示原 MySQL 分析链路，Hive 阶段优先迁移客户价值、国家销售和高价值客户偏好相关核心指标。

五、客户价值分层规则
High Value：total_spent >= 5000
Medium Value：1000 <= total_spent < 5000
Low Value：total_spent < 1000

六、结果解释边界
1. 本项目所有指标均基于当前数据集统计，不等同于真实业务运营指标。
2. 本项目不将分析结果表述为实际业务优化收益。
3. 项目结果主要用于展示离线数仓建模、指标开发、Hive 迁移、调度编排和结果校验能力。
4. 结果截图中的日期为演示业务日期，用于展示分区重跑和调度验收效果。

## 验证口径

本项目通过 `bizdate` 参数控制业务日期，各层 Hive 表统一使用 `dt` 分区保存结果。主链路采用 `INSERT OVERWRITE PARTITION` 覆盖写入指定业务日期分区，因此支持单日重跑、区间回刷和 T+1 修正窗口。

多天验证数据用于证明分区回刷能力，不表述为真实业务连续 7 天数据。截图仅作为项目运行验收示例，不作为真实业务运营结论。


## 补充说明（DWD 清洗质量截图字段说明）

`06_dwd_cleaning_quality_20260401.png` 展示 `2026-04-01` 分区的 DWD 清洗质量检查结果，字段依次为：

```text
业务日期
异常数量记录数
异常价格记录数
空客户记录数
退货订单记录数
```

说明：

- 异常数量：Quantity <= 0
- 异常价格：Price <= 0
- 空客户：CustomerID 为空或空字符串
- 退货订单：Invoice 为空或以 C 开头的退货订单

各异常项按条件分别统计，同一条记录可能同时命中多个异常条件，因此异常项数量之和不一定等于 ODS 与 DWD 的行数差。

## 2. “ODS”在本目录中的含义

本目录截图中的：

```text
ods_retail_hive
```

指正常业务 ODS，不是后来新增的：

```text
ods_retail_raw_hive
ods_retail_reject_hive
```

这些截图生成时，Raw、Reject 和 ODS 入仓完整性门禁尚未加入主链路。

因此不能使用这些截图证明：

- 源表与 ODS Raw 已完成对账；
- 日期异常已进入 Reject；
- 当前三组 ODS 入仓断言已经通过。

上述能力应以当前 `2026-04-08` 回归结果为准。

## 4. 幂等性截图说明

`04_idempotency_check_20260403.png` 显示以下 3 张表重跑前后的行数一致：

```text
ods_retail_hive
dwd_retail_clean_hive
ads_country_sales_rank_hive
```

截图中的检查方式是：

```text
before_cnt = after_cnt
```

它能够证明当时这 3 张表没有因重复执行而追加行数，但不能单独证明所有字段内容完全一致。

当前仓库中的：

```text
hive_sql/run_idempotency_check_hive.sh
```

已扩展为：

- 检查 8 张核心 ODS / DWD / DWS / ADS 表；
- 同时比较行数；
- 比较两组 CRC32 内容指纹。

因此本截图属于旧版基础幂等性验收证据，当前脚本能力比截图中展示的更完整。

## 6. DWD 清洗质量截图说明

`06_dwd_cleaning_quality_20260401.png` 的字段顺序为：

```text
业务日期
异常数量记录数
异常价格记录数
空客户记录数
取消或退货订单记录数
```

截图结果：

```text
业务日期：2026-04-01
异常数量：68,850
异常价格：18,675
空客户：729,021
取消或退货订单：58,482
```

对应条件：

```text
异常数量：
Quantity <= 0

异常价格：
Price <= 0

空客户：
CustomerID 为空或空字符串

取消或退货订单：
Invoice 为空或以 C 开头
```

各类异常按条件分别统计，同一记录可能同时满足多个条件。因此：

```text
四类异常数量之和
```

不一定等于：

```text
正常 ODS 行数 - DWD 行数
```

该截图属于内容检查，不是当前的 DWD 质量日志门禁截图。

## 7. 与当前回归结果的区别

本目录的历史基线：

```text
正常 ODS：3,202,113
DWD：3,124,956
国家：43
```

当前 `2026-04-08` 完整回归：

```text
源表：3,202,113
ODS Raw：3,202,113
正常 ODS：3,202,113
Reject：0
DWD：2,416,593
fact_order：2,416,593
国家：41
总销售额：53,230,287.48
```

两组结果来自不同阶段的数据或清洗规则基线，不能直接比较，也不能据此判断某一组结果错误。

仓库中的统一解释应为：

> 历史截图证明分区重跑、T+1 和基础幂等性流程曾经运行成功；当前 `2026-04-08` 数据用于证明最新 Raw、Reject、质量门禁和星型模型链路运行成功。

## 9. 使用边界

本目录截图可以证明：

- 脚本可以接收多个 `bizdate`；
- Hive 表可以保存多个 `dt` 分区；
- 指定日期可以重复执行；
- T+1 两日窗口可以运行；
- 旧版 3 表行数检查曾通过；
- DWD 清洗条件可以被统计。

本目录截图不能单独证明：

- 当前 ODS Raw 和 Reject 链路；
- 当前三组 ODS 入仓对账；
- 当前 8 表双指纹幂等性；
- 当前 DWS/ADS 结果门禁；
- 当前星型模型和 SCD2 多版本变化；
- 真实业务连续 7 天数据变化；
- 当前完整链路已经在 DolphinScheduler 中全部调度化。
